# LIVEKEN LOGISTICS

### Moving Africa. Connecting the World.

A modern logistics company website concept based around the Port of Mombasa, Kenya.

## Services

- Sea Freight
- Air Freight
- Container Haulage
- Customs Clearance
- Warehousing
- Supply Chain Management

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive website design
- Interactive navigation
- Animated statistics
- Shipment tracking demonstration
- Fleet showcase
- Quotation request form
- Contact information

## Project Structure

liveken-logistics/

- index.html
- style.css
- script.js
- README.md
- images/

## How to Run

1. Open the project in Visual Studio Code.
2. Install Live Server.
3. Open index.html.
4. Right-click and select Open with Live Server.
